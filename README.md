Plantilla web profesional para pequeños negocios: catálogo de productos con pedidos directos a WhatsApp.

## ✨ Características

- 📱 Diseño **mobile-first** y 100% responsive
- 💬 Botones de WhatsApp con **mensaje prellenado** por producto
- 🎨 Paleta de colores personalizable por variables CSS
- ⚡ Cero dependencias — solo HTML5, CSS3, PHP y JS vanilla
- 🔍 SEO básico y HTML semántico
- 🚀 Listo para desplegar en cualquier servidor con PHP

## 🛠️ Tecnologías

- PHP 7.4+
- HTML5 semántico
- CSS3 (Grid + Flexbox)
- JavaScript vanilla
- Google Fonts (Poppins)

## 🚀 Instalación local (XAMPP)

1. Copia la carpeta a `C:\xampp\htdocs\plantilla-landing\`
2. Inicia **Apache** en el panel de XAMPP
3. Abre: `http://localhost/plantilla-landing/`

## ⚙️ Personalización en 3 pasos

Edita el inicio de `index.php`:

1. **`$NEGOCIO`** → nombre, WhatsApp, email, redes
2. **`$PRODUCTOS`** → tu catálogo (nombre, precio, imagen)
3. **`$COLORES`** → paleta del cliente
